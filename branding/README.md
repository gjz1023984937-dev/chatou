# Chatou branding

Chatou（中文名“插头”）的图标把三件事合并成一个符号：蓝色电源插头、文字输入光标，以及代表 AI 转换的紫色星光。图标采用透明背景，适合 Windows 应用标题栏、安装器和仓库头像。

## Files

- `chatou-logo-master.png` — 原始生成图
- `chatou-logo.png` — 512 × 512 标准 PNG
- `chatou.ico` — Windows 多尺寸图标
- `../docs/assets/chatou-social-preview.jpg` — GitHub 社交分享封面（1280 × 640）

## Generation brief

Built-in image generation mode was used with this final brief:

> Create a minimal, professional app icon for “Chatou”, a Windows AI translation input method. Use one bold blue electrical plug merged with a vertical text cursor, plus one small violet AI sparkle. Flat vector geometry, rounded corners, crisp silhouette, transparent background, no text, no letters, no mockup, no shadow, readable at 16 px, centered with generous padding. Microsoft Fluent-inspired but original; royal blue and violet only.

The generated artwork was cropped, padded and exported to the application-specific PNG and ICO formats used by the Windows build.

The social preview was generated in built-in image generation mode from the existing logo with the exact copy “Chatou 插头” and “输入中文 · 按 F8 · 原地变成你想说的话”, then exported as a solid-background 1280 × 640 JPEG for GitHub sharing.
