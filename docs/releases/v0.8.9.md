# Chatou 插头 v0.8.9 测试版

本测试版用于验证微信、资源管理器重命名框和 Microsoft Word 等非浏览器文本控件的兼容性。

## 兼容性修复

- 保留首选的 Windows TSF 校验事务；
- 原生 Edit/RichEdit 控件拒绝 TSF 范围改写时，使用经过原文校验的原生控件替换；
- 自定义文本控件拒绝以上两种方式时，使用选择原文并直接注入 Unicode 的兼容路径；
- 兼容路径不使用剪贴板，也不会向输入框提交 Chatou 内部控制串；
- 修复 Word 等宿主占用 `F8` 时可能导致 Chatou 输入法激活失败、系统切换到其他输入法的问题；
- 翻译等待期间额外校验实际获得焦点的输入控件，降低在同一窗口内切换输入框后误替换的风险；
- TSF 成功改写文字但拒绝显式移动光标时，不再错误执行第二次替换。

## 测试重点

1. 微信聊天输入框中输入中文后按 `F8`；
2. 资源管理器中重命名文件，输入中文名称后按 `F8`；
3. Word 中确认右下角仍为 Chatou，输入中文后按 `F8`；
4. 三种场景分别测试转换后 `Ctrl + Z`，以及紧接着再次按 `F8`；
5. 翻译等待期间切换到另一个输入框，确认旧结果不会覆盖新位置。

这是验证安装包；确认以上场景后再发布为正式版本。
