# Chatou 插头 v0.8.8

Chatou 是一款 Windows 系统级 AI 表达输入法：照常输入中文，按下 `F8`，文字就会在当前输入框中原地转换成你需要的语言或语气。

## 普通用户下载

请下载 **`Chatou-Installer-v0.8.8.exe`**。安装包适用于 Windows 10/11 x64。

安装完成后：

1. 填写自己的模型 API Key；
2. 按 `Win + Space` 切换到“Chatou 插头”；
3. 输入拼音并选出中文；
4. 按 `F8` 转换。

`Chatou-v0.8.8-package.zip` 面向需要查看或手动处理打包文件的高级用户，普通安装不需要下载。

## v0.8.8 热修复

- 修复部分应用（包括微信）按 `F8` 时可能把 Chatou 内部控制串插入输入框的问题；
- 模型结果改走独立 IPC 数据通道，内部替换指令不再作为普通文字提交给应用；
- 修复转换后按 `Ctrl + Z` 恢复原文，再立即按 `F8` 无法重新转换的问题；
- 撤销后的原文只允许紧接着重译一次；如果继续输入、移动光标或执行其他按键，该待重译状态会立即取消，不会与后续文字一起转换；
- 保留替换前的原文与光标校验，当前输入框内容不匹配时不会覆盖文字。

建议已经安装 v0.8.7 的用户升级到 v0.8.8。

目前安装包尚未进行商业代码签名，Windows SmartScreen 可能提示“未知发布者”。请确认下载地址属于本仓库并核对摘要后再运行。

## 隐私与已知限制

- Chatou 没有自己的中转服务器，文字会直接发送到用户配置的模型地址；
- 使用 Ollama 等本地兼容服务时，文字可以只在本机处理；
- API Key 当前保存在本机配置文件中，尚未使用 Windows 凭据保险库加密；
- 本机诊断日志可能包含截断后的输入和模型响应，不会被 Chatou 自动上传；
- 当前仅支持 Windows 10/11 x64。
