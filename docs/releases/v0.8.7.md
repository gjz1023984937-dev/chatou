# Chatou 插头 v0.8.7

Chatou 是一款 Windows 系统级 AI 表达输入法：照常输入中文，按下 `F8`，文字就会在当前输入框中原地转换成你需要的语言或语气。

## 普通用户下载

请下载 **`Chatou-Installer-v0.8.7.exe`**。安装包适用于 Windows 10/11 x64。

安装完成后：

1. 填写自己的模型 API Key；
2. 按 `Win + Space` 切换到“Chatou 插头”；
3. 输入拼音并选出中文；
4. 按 `F8` 转换。

`Chatou-v0.8.7-package.zip` 面向需要查看或手动处理打包文件的高级用户，普通安装不需要下载。

## v0.8.7 更新

- 设置页新增“最近使用”风格记录，自动去重并保留最近 8 项；
- 将模型结果回填从剪贴板与模拟退格改为受校验的 Windows TSF 文本编辑事务；
- 转换完成后可立即按 `Ctrl + Z` 恢复原文；
- 原文、光标或窗口发生变化时不会错误覆盖当前文本；
- 没有可恢复的 Chatou 转换时，撤销快捷键继续交给当前应用处理；
- 保留 `Ctrl + Shift + Z` 等应用原生重做快捷键。

目前安装包尚未进行商业代码签名，Windows SmartScreen 可能提示“未知发布者”。请确认下载地址属于本仓库并核对摘要后再运行。

## 隐私与已知限制

- Chatou 没有自己的中转服务器，文字会直接发送到用户配置的模型地址；
- 使用 Ollama 等本地兼容服务时，文字可以只在本机处理；
- API Key 当前保存在本机配置文件中，尚未使用 Windows 凭据保险库加密；
- 本机诊断日志可能包含截断后的输入和模型响应，不会被 Chatou 自动上传；
- 当前仅支持 Windows 10/11 x64。
